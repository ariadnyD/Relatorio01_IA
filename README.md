## Descrição
Este repositório contém a análise exploratória e o pré-processamento de dados para a atividade da disciplina DCT1401 - Inteligência Artificial. O objetivo é preparar o dataset bruto para dois problemas distintos: regressão e classificação.

## Estrutura do Repositório
- `data/raw/`: Dataset original (não modificado)
- `data/processed/`: Datasets após a limpeza e pré-processamento
- `notebooks/`: Notebooks interativos com as etapas da análise
- `reports/figures/`: Gráficos gerados durante a exploração
- `src/`: Funções auxiliares do projeto

## Como Executar
1. Clone este repositório em sua máquina.
2. Instale as dependências necessárias executando no terminal: `pip install -r requirements.txt`
3. Abra e execute os notebooks na ordem numérica correta:
   - `01_eda.ipynb` (Análise Exploratória)
   - `02_preprocessing.ipynb` (Limpeza e Pré-processamento)
   - `03_regression_analysis.ipynb` (Percepções para Regressão)
   - `04_classification_analysis.ipynb` (Percepções para Classificação)
